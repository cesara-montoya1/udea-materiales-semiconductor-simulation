# Semiconductor Materials & Photodetector Numerical Simulation

> [!NOTE]
> **Archived Academic Project**  
> This repository is a read-only historical archive of coursework developed for academic evaluation.

## Overview
Numerical simulation framework for semiconductor materials and optoelectronic photodetector dynamics, developed for the **Materiales en Ingeniería** course at **Universidad de Antioquia**.

## Implemented Physics & Models
* **Intrinsic & Extrinsic Carriers**: Temperature-dependent Fermi-Dirac statistics, intrinsic carrier concentration ($n_i$), and effective density of states.
* **Transport Dynamics**: Carrier mobility models, drift velocity saturation, and conductivity as a function of doping concentration.
* **Photodetector Modeling**: Optical absorption coefficient ($lpha$), quantum efficiency ($\eta$), responsivity ($\mathcal{R}$), and dark current characteristics.

## Technologies
* Python (NumPy, SciPy, Matplotlib)
* Jupyter Notebook (`main.ipynb`)
